# Superstore Sales Dashboard

An exploratory data analysis project investigating retail transaction data to identify sales performance patterns and outliers.

## What it does
- Investigated 9,800 transaction records across categories, regions, and shipping methods.
- Identified performance patterns and outliers through systematic exploratory analysis.
- Visualized findings to surface actionable insights on where sales underperform or spike.

## Why I built it
Wanted hands-on practice turning a raw transactional dataset into decision-ready insights — the same analytical process used for telemetry and trace-data evaluation, applied here to retail sales data.

## Tech stack
Python · Pandas · Power BI / Excel · Data Visualization

## How to run
```bash
pip install -r requirements.txt
jupyter notebook analysis.ipynb
```
